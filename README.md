# OPO.APT

Site dos apartamentos OPO.APT, no Porto: sete apartamentos num prédio Art Déco de 1936,
na Praça de Pedro Nunes, entre Cedofeita e a Boavista.
Site estático (HTML, CSS e JS, sem build): abre `site/index.html` ou publica a pasta `site/`.

- `site/index.html` — a página de entrada: o prédio, os sete apartamentos, o bairro e as reservas.
- `site/112-d-deco/`, `site/114-0-pateo/` e `site/112-r-terraco/` — a página de cada apartamento.
- `site/assets/` — estilos, scripts e fotografias.
- `netlify.toml` — publica só a pasta `site/`.

Fotografias da região: Wikimedia Commons (créditos no rodapé do site). Mapas: © colaboradores do OpenStreetMap.
